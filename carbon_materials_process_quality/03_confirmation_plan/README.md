# 03. 탄소소재 활성화 조건 확인실험 제안

> 상태: **예비 실험설계 초안 / 실제 실험 미수행 / 실행 NO-GO**. K/C의 실제 투입량 환산, 원료별 실현 가능성, 실험안전 및 표본수 타당성이 검증되지 않았습니다. 공개 연구자료를 바탕으로 확인실험 방향을 제안한 것이지, 제조조건 승인이나 공정개선 실적이 아닙니다.
>
> [공학적 타당성 최종 검토](./TECHNICAL_REVIEW.md) · [실험 전 판단·승인 양식](./PRE_RUN_DECISION_TEMPLATE.md)

## 제조 엔지니어의 다음 판단

기존 [02 제조조건–BET 분석](../02_process_relationships/)에서 800°C 고정 연구 시료 49개의 K/C와 BET는 음(-)의 상관을 보였습니다. 그러나 O/C와 K/C의 상관이 매우 높고, 단순 상관과 다중회귀에서 O/C의 방향도 바뀌었습니다.

따라서 단순히 회귀계수가 높은 변수를 조작하거나 BET가 가장 높게 나온 조건을 선택해서는 안 됩니다. **원료 LOT를 고정한 채 K/C를 변화시켜, BET의 방향이 재현되는지 직접 확인**해야 합니다.

실험이 답해야 할 질문은 다음과 같습니다.

1. 동일 원료 LOT에서 K/C를 변경하면 BET의 변화가 일관되게 나타나는가?
2. 원료 LOT가 달라지면 K/C 변화의 방향이나 크기가 달라지는가?
3. BET 증가 가능성이 있더라도 수율, 잔류 K, 기공 특성, 공정 안전성까지 만족하는가?
4. 어느 조건까지 실험 근거가 있고, 어느 지점은 추가 확인이 필요한가?

## 1. 공개 데이터에서 확정한 범위

University of Nottingham / Nanolayers의 [Zenodo v2 활성탄 데이터](https://zenodo.org/records/23311682) 중 MAST3RBoost 연구 시료 49개만 참조했습니다.

| 항목 | 관측 조건 | 제안서에서의 역할 |
|---|---|---|
| 활성화 온도 | 모든 시료 800°C | 온도 고정 인자 (최적 온도 아님) |
| 유지시간 | 모두 1 hour | 고정 조건 제안 |
| 승온속도 | 모두 3°C/min | 고정 조건 제안 |
| Porogen·compactivation | 두 표시변수 모두 0 | 해당 조건을 유지하는 설계 |
| K/C | 다양한 값 | 유일하게 계획적으로 변화시키는 공정 변수 |
| O/C·N/C | 원료 조성과 함께 변화 | 원료 LOT별 측정 및 기록 대상 |
| BET | 49개 관측값 | 주된 품질 응답 |

K/C는 원본에서 **무차원 원소 조성비**로 정의됩니다. K/C 수치를 투입 약품의 중량비나 KOH 투입량으로 그대로 바꿀 수 없습니다. 실제 공정에서 시약 투입량으로 매핑하려면 원료 원소 분석, 활성화제 종류·순도, 반응 전 물질수지, 설비 허용조건을 먼저 확인해야 합니다.

## 2. 실험조건 선정 근거

연구 시료 49개의 K/C 분포에서 사분위수를 구해 **관측 범위 안의 3개 탐색 수준**을 제안합니다. 특정 BET 예측값이 최대가 되도록 모형을 최적화하지 않았습니다.

| 가상 수준 | K/C 목표(무차원) | 출처 |
|---|---:|---|
| LOW | 약 2.946 | 원본 K/C의 25% 분위수 |
| CENTER | 약 3.322 | 원본 K/C 중앙값 |
| HIGH | 약 3.764 | 원본 K/C의 75% 분위수 |

이 값들은 실험설계용 탐색 후보입니다. **실제 제조 Recipe, 안전 운전범위, 양산 최적조건이 아닙니다.** 관측 분포의 분위수라도 동일 원료 LOT에서 모두 구현 가능하거나 물리화학적으로 타당하다는 보장은 없습니다. 원본 K/C는 무차원 조성비로 표시되어 있으며, 이를 KOH 투입 중량비나 실제 설비 설정값으로 간주할 수 없습니다. K/C 산식과 시약 화학종·원료 탄소함량·물질수지 확인 전에는 실행하지 않습니다.

온도는 800°C로 유지하고, 서로 다른 원료 LOT 2개를 각 K/C 수준에서 비교하는 구조입니다.

## 3. 실험 설계: 독립 제조 12회

원료 LOT (2개) × K/C (3개 수준) × 독립 제조 반복 (2일) = **12개 독립 실험 제조**

| 인자 | 수준 | 목적 |
|---|---|---|
| 원료 LOT | F-A, F-B (아직 지정되지 않은 가상 표시) | 원료에 따른 차이·상호작용 탐색 |
| K/C | LOW, CENTER, HIGH | 같은 LOT 내에서 K/C 수준의 변화 비교 |
| 실험일 | D1, D2 (각 조합 1회/일) | 일자별 공통 변동과 재현성 관찰 |
| 활성화 온도 | 800°C 고정 | 온도 차이에 의한 혼동 최소화 |
| 유지시간/승온속도 | 1 hour / 3°C/min | 참고 시료와 기록조건 일치 |

각 실험일마다 LOT × K/C 여섯 조합을 모두 한 번씩 수행하고, 실험일 내 순서를 고정 시드로 무작위 배치했습니다. 두 날에 동일한 조합을 반복합니다. 같은 시료를 두 번 측정한 것을 독립 실험 반복으로 취급하지 않습니다.

본 설계는 검정력이 확인된 본실험이 아닙니다. 실험일·원료 LOT·K/C 및 LOT×K/C를 포함하는 단순 선형모형을 가정하면 총 12회에서 잔차 자유도는 5입니다. 원료 LOT 2개와 일자 2개만으로 일반화하기 어렵고, 본실험 전 제조 간 산포와 최소 실무상 의미 있는 차이를 바탕으로 반복수를 다시 산정해야 합니다.

[12회 제안 실험조건표](./results/DESIGN_MATRIX.csv) · [결과 기록 양식(빈 값)](./results/MEASUREMENT_LOG_TEMPLATE.csv) · [출처 기반 수준 계산 결과](./results/DESIGN_EVIDENCE.json)

실험조건표의 모든 행은 **PROPOSED_NOT_EXECUTED**이며 실행 승인은 **NO_GO_PENDING_FEASIBILITY_AND_SAFETY**입니다. 결과 기록 양식에는 측정값이 입력되지 않았습니다.

## 4. 측정해야 할 CTQ와 운영 제약

| 구분 | 기록 또는 측정 | 판단 의미 |
|---|---|---|
| 1차 CTQ | BET 비표면적 (m²/g) | 목적 특성, 동일 측정법으로 평가 |
| 시험 신뢰성 | 실험 제조별 BET 시험 2회 | 분석 반복성 점검. 독립 제조 반복과 구별 |
| 부가 CTQ | 기공부피, 기공분포(방법 명시) | BET 단독 평가의 한계 보완 |
| 수율 | 건조 전구체 질량 대비 회수 질량 | 높은 BET와 생산량·경제성의 상충 확인 |
| 품질·정제 | 잔류 K/회분, 오염물질 | 약품 사용량 증가에 따른 품질 위험 |
| 공정 이력 | 실제 온도곡선, 가열분위기, 유량, 유지시간 | 목표 설정값이 아니라 실행 실적 검증 |
| 원료 이력 | COA, O/C·N/C, 원료 제조 LOT | 원료차와 K/C차를 혼동하지 않기 위해 필요 |
| 경제성 | 약품 사용량, 에너지 사용량, 폐기물 | 조건 변경의 실제 원단위 영향 평가 |

자료에 없는 제품 규격이나 원가 수치를 임의로 정하지 않았습니다. 실험 시작 **전**에 BET 목표, 최소 수율, 허용 잔류물, 에너지/원가 제약, 반복시험 허용차, 공정안전 승인 기준을 공정 담당자가 확정해야 합니다.

## 5. 실험 전 Go / No-Go

1. **물리·화학 실행 가능성:** 실험 대상 원료 2종에서 세 K/C 목표를 실제 시약투입·원소분석 기준으로 구현할 수 있는지 검토. 불가능하면 임의로 숫자를 끼워 맞추지 않고 설계를 수정.
2. **설비·안전성:** 고온 활성화, 약품, 배출·중화, 설비 허용 온도와 가스 분위기를 사전 검토. 승인받지 않은 조건으로 실험하지 않음.
3. **시험·품질:** BET 시험법, 시료 채취·전처리, 기공분석법, 분석 반복성 및 기준값을 사전 확정.
4. **실행 가능성:** 동일 로트 재료 확보, 실험일에 모든 조건 배치 가능 여부, 장비 점유·위치 효과 및 실험순서 무작위화 가능 여부 검토.
5. **사전 판단 기준:** 허용 산포, 최소 실무상 유의한 BET 차이, 수율·오염물질 제약을 실험 전에 서면화.

이 과정을 통과하기 전에는 **12회 실험을 수행하라는 실행 지시로 사용하지 않습니다.**

## 6. 데이터 확보 후 평가 방법

1. 데이터 완전성 확인: 각 12개 제조가 실제 수행됐는지, 실제 K/C·온도 프로파일·COA·시험법이 기록됐는지 점검.
2. 측정 신뢰성 구분: 제조 반복 12개와 BET 시험 반복 24개(예정)를 구분. 시험 반복을 독립 제조 N으로 부풀리지 않음.
3. **동일 원료 LOT 내 비교:** 낮음→중앙→높음 세 수준의 BET를 비교하고, 두 날의 방향이 일치하는지 확인.
4. **LOT별 차이:** 두 원료 LOT에서 K/C의 변화 방향이 달라지는지 확인. 원료 효과는 LOT 2개로 일반화하지 않음.
5. **운영 제약 검토:** BET가 높더라도 수율·잔류물·원단위나 공정안전 기준을 충족하지 못하면 채택 보류.
6. **후속 판단:** 일관된 차이가 재현되면 동일 원료·조건 범위의 추가 반복 확인실험을 설계. 방향이 불안정하면 원료·측정·설비 요인부터 분리.

표본이 12개에 불과해 통계적 검정력은 낮습니다. p값만으로 결론을 내리지 않고 추정 효과의 크기, 반복 간 변동, 품질과 수율의 상충, 실험조건의 실행 가능성을 종합해 판단하도록 계획합니다.

## 7. 프로젝트의 의미와 한계

- **보여주는 역량:** 공개 제조 연구데이터에서 데이터의 한계를 확인하고, 원료·공정조건의 교란을 줄이는 다음 실험을 설계하며, 품질·원단위·안전까지 함께 검토하는 접근.
- **보여주지 않는 것:** 실제 실험 수행, 인과효과 검증 완료, 실험실·Pilot Scale-up 성공, 공정 최적화, 비용 절감.
- **원본 보존:** 연구 원본 CSV나 행 단위 변형자료를 공개하지 않음. GitHub에는 연구 요약, 직접 작성한 계획, 빈 측정 양식만 게시.
