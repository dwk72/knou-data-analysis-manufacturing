## 2. 판정 기준 선등록

| 의사결정 변수 | 규격·최소 실무상 의미 있는 차이 | 미충족 시 행동 |
|---|---|---|
| BET 비표면적 | 미정 (규격 및 반복측정 허용차 설정 필요) | 조건 채택 보류 |
| 기공부피 및 관련 물성 | 미정 | 후속 시험 검토 |
| 건조 투입량 대비 회수 수율 | 미정 | 원단위/수율 조사 |
| 잔류 K·회분 | 미정 | 정제·오염 위험 검토 |
| 에너지 원단위 및 활성화제 원단위 | 미정 | 경제성 검토 |
| 환경·안전·설비 제약 | 미정 | 해당 실험 시행 금지 |

수치는 공개 연구데이터에 제조제품 규격과 경제성 가중치가 없어 임의로 입력하지 않았습니다. `BET 높음 = 채택` 기준은 허용하지 않습니다.

## 3. 사전 분석 규칙

1. 독립 제조 단위는 `experiment_id` 12개입니다. 동일 시료의 BET 2회 측정은 시험 반복으로 보고 제조 반복수에 더하지 않습니다.
2. 각 제조 결과에서 목표 대비 실제 K/C, 실제 온도 프로파일, 질량수지와 품질시험의 누락 여부를 우선 확인합니다.
3. 1차 대비는 같은 원료 LOT 안의 K/C LOW–CENTER–HIGH 변화입니다. 각 원료 LOT는 두 실험일에서 동일한 조건을 반복합니다.
4. 두 LOT 간 수준별 반응이 다르면 상호작용 가능성을 기록합니다. LOT 2개로 모든 원료를 일반화하지 않습니다.
5. BET와 수율/잔류물/원단위를 공동으로 보고, 정해둔 품질·안전 기준에 부적합한 조건은 채택하지 않습니다.
6. 독립 반복 2회는 예비 확인 수준입니다. 불확실성이 크거나 효과가 작다면 추가 반복 또는 다른 원료 LOT를 대상으로 확인실험을 설계합니다.
7. 통계 검정 결과 하나만으로 최적조건, 공정 개선, 인과관계가 확정됐다고 표현하지 않습니다.
