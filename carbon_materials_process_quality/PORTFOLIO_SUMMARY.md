# 탄소소재 제조조건·품질 데이터 분석 | 포트폴리오 요약

화학공정·탄소소재 생산기술 관점에서 공개 활성탄 연구데이터의 신뢰성을 검토하고, 원료·활성화 조건과 BET 비표면적의 관계를 분석한 뒤 후속 확인실험의 **미실시 제안서**를 작성한 사례입니다.

> 공개 연구데이터 분석 프로젝트. 실제 회사 양산 Batch·제조시험·공정개선 실적이 아니며 확인실험은 수행하지 않았습니다.

## 제조 문제와 분석 목적

서로 다른 연구에서 얻은 원료 조성·활성화 온도·제품 물성 자료를 단순 결합하면 원료/측정법/제조조건 차이를 공정 효과로 오해할 수 있습니다. 생산기술 엔지니어가 실제 조건 변경을 검토하기 전에 무엇을 신뢰할 수 있고, 추가로 무엇을 검증해야 하는지 판단하는 흐름을 만들었습니다.

## 확인된 결과와 엔지니어링 판단

| 확인한 내용 | 검증 수치·증거 | 다음 판단 |
|---|---|---|
| 연구자료의 비교 가능성 | 공개 활성탄 시료 **237개**, 문헌 188개 / 프로젝트 49개, BET 관측 225개 | 동일한 제조실험의 반복으로 취급하지 않음 |
| 활성화 온도와 물성 | 문헌의 600·700·800°C 시료 중 BET 관측 **162개**. 그룹별 평균 BET 증가 경향 | 출처·원료·제조조건이 달라 온도의 인과효과로 해석하지 않음 |
| 원료 조성과 물성 | 프로젝트 시료 **49개는 모두 800°C**, K/C–O/C 상관 **+0.918** | 온도효과 추정 불가, 조성 간 교란 가능성 확인 |
| 회귀 결과의 한계 | O/C–BET 단순 상관은 음(-), 다중회귀 계수는 양(+) | 단일 상관/회귀계수로 Recipe 변경 금지 |
| 다음 검증 제안 | 원료 LOT 2개 × K/C 3수준 × 실험일 2회 = **12회 제조를 가정한 예비 설계** | 실제 K/C 구현, 위험성·시험법·표본수 승인 전 **NO-GO** |

## 수행 범위 및 산출물

- 공개 원본 무결성·스키마·측정 누락 검증, 출처별 분석
- 온도·원료 조성과 BET의 탐색적 관계, 다중회귀·부트스트랩·교차검증
- 상충하는 변수 관계와 데이터 한계 문서화
- 독립 제조 vs 분석 반복을 구분한 실험조건표, 빈 측정기록 양식, 실행 전 승인 기준서
- Python 코드와 GitHub Actions 재현성 검사

## 채용 직무와의 연결

탄소소재 Scale-up·생산기술 직무에서 중요한 것은 회귀모형의 정확도를 높이는 것만이 아닙니다. 원료 변화와 공정조건을 구분하고, 품질 특성 외에 제조 수율·잔류물·에너지 원단위·설비·안전을 함께 검토해 다음 실험을 결정하는 과정입니다.

이 사례는 그 **데이터 검토 및 실험계획 역량**을 보여줍니다. 실제 제조에서의 문제해결·양산개선 성과를 대체하지는 않습니다.
