# 02. Multivariate Analysis

## 이 프로젝트에서 한 일

KNOU 다변량분석 과제에서 R과 Python을 이용해 **여러 변수의 관계를 동시에 파악하는 분석**을 수행했습니다.

단일 변수만 보는 것이 아니라, 변수들이 서로 어떻게 움직이는지 확인하고 복잡한 정보를 더 적은 수의 축으로 요약하는 것이 핵심입니다.

### 1. 기술통계와 상관분석

먼저 각 변수의 분포와 변수 간 관계를 확인했습니다.

- 히스토그램으로 값의 분포 확인
- 산점도행렬로 변수 간 관계 시각화
- 상관계수행렬로 함께 증가하거나 감소하는 변수 확인

### 2. 주성분분석(PCA)

PCA는 여러 변수를 몇 개의 대표 축으로 줄여 전체적인 데이터 구조를 보는 방법입니다.

수행 내용:
- 변수 표준화
- 고윳값과 설명분산 확인
- Scree plot으로 사용할 주성분 수 판단
- 주성분계수 해석
- Biplot으로 관측치와 변수 관계를 함께 확인
- R과 Python 결과 비교

과제에서는 고윳값이 1보다 큰 주성분 3개를 유효한 주성분으로 해석했고, R과 Python의 결과가 부호 차이를 제외하면 동일한 구조를 보임을 확인했습니다.

### 3. 인자분석(Factor Analysis)

인자분석은 여러 관측변수 뒤에 숨어 있는 공통된 요인을 찾는 방법입니다.

수행 내용:
- 인자분석 적용 가능성 확인
- 유효 인자 수 선정
- 인자부하량 해석
- Varimax / Promax 회전
- 회전 전후 결과 비교
- R과 Python 결과 비교

과제에서는 2개의 유의한 인자를 선정해 각 변수군의 공통 특성을 해석했습니다.

## 사용 기술

`R` · `Python` · `Correlation` · `PCA` · `Factor Analysis` · `Scree Plot` · `Biplot`

## 제조업과의 연결 방향

현재 분석 대상은 제조 데이터가 아닙니다. 이후에는 같은 분석 방법을 공정 데이터에 적용할 예정입니다.

예를 들어 온도, 압력, 유량, 속도, 품질값처럼 서로 연관된 변수가 많을 때 다음과 같이 활용할 수 있습니다.

- 서로 강하게 연관된 공정변수 확인
- 여러 변수를 몇 개의 대표 축으로 요약
- 정상 LOT와 이상 LOT의 위치 차이 확인
- 어떤 변수들이 차이를 만드는지 후보를 좁히기

이 프로젝트는 **복잡한 다변수 데이터를 구조적으로 해석할 수 있는 기초 역량**을 보여주는 사례입니다.
