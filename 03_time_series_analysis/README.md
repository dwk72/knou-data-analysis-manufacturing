# 03. Time-Series Analysis

## 이 프로젝트에서 한 일

KNOU 예측방법론 과제에서 2000~2025년 월별 전산업생산지수를 이용해 **시간에 따라 데이터가 어떻게 변하는지** 분석했습니다.

시계열 분석의 목적은 단순한 평균 비교가 아니라, 데이터 속에 있는 추세·주기·반복 패턴을 구분해서 보는 것입니다.

### 분석 순서

1. 원계열과 계절조정계열을 그래프로 비교
2. Spectrum으로 반복 주기 확인
3. 로그변환으로 값의 변동폭 조정
4. 차분을 통해 시간에 따른 변화량 확인
5. ADF 검정으로 시계열의 정상성 확인
6. ACF / PACF로 과거 값과 현재 값의 관계 확인

정리된 R 코드는 [industrial_production_analysis.R](./industrial_production_analysis.R)에 있습니다.

## 용어를 간단히 설명하면

- **계절성**: 일정한 간격으로 반복되는 패턴
- **Spectrum**: 어떤 주기가 강하게 반복되는지 확인하는 방법
- **차분**: 현재 값에서 이전 값을 빼 변화량을 보는 방법
- **ADF 검정**: 시계열이 안정적인 특성을 가지는지 확인하는 통계 검정
- **ACF / PACF**: 과거 값이 현재 값과 어느 정도 관련되는지 보는 지표

## 사용 기술

`R` · `zoo` · `ggplot2` · `spectrum` · `log transform` · `differencing` · `ADF` · `ACF` · `PACF`

## 제조업과의 연결 방향

제조현장에는 시간순으로 쌓이는 데이터가 많습니다.

예:
- 반응기 온도·압력·유량
- 설비 전류·진동
- 생산량
- 수율
- 불량률
- 에너지 사용량

현재 과제에서 사용한 시계열 분석 흐름을 적용하면 다음과 같은 질문으로 확장할 수 있습니다.

- 공정값이 시간에 따라 서서히 변하고 있는가?
- 특정 주기로 반복되는 변동이 있는가?
- 평소와 다른 변화가 언제 시작됐는가?
- 품질 저하 이전에 공정값 변화가 있었는가?

현재는 제조 데이터를 직접 분석한 단계가 아니며, 이후 합성 제조 데이터로 확장할 예정입니다.
