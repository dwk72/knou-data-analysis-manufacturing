# 01. Python Data Pipeline

## 이 프로젝트에서 한 일

KNOU 과제에서 Python으로 공공 데이터를 직접 받아오고, 분석할 수 있는 표 형태로 정리했습니다.

쉽게 말하면 아래 과정을 코드로 구현한 것입니다.

```text
외부 데이터 가져오기
      ↓
JSON 파일로 저장
      ↓
필요한 항목만 선택
      ↓
날짜·숫자 형식 정리
      ↓
여러 기간의 데이터 합치기
      ↓
CSV로 저장
```

이 과정은 흔히 **ETL(Extract–Transform–Load)**이라고 부릅니다.

- Extract: 외부에서 데이터 가져오기
- Transform: 분석하기 좋은 형태로 정리하기
- Load: 정리된 데이터를 저장하기

### Case A. 월별 대기질 데이터

Python의 `requests` 라이브러리로 월별 공공 API를 호출하고, 응답받은 JSON 데이터를 저장한 뒤 `pandas`로 표 형태로 변환했습니다.

수행 내용:
- 월별 API 호출
- JSON 응답 저장
- 날짜·측정소·PM10 항목 선택
- 날짜형·문자형·숫자형으로 데이터 형식 정리
- 결측치 제거
- 여러 달의 데이터를 하나로 통합
- CSV 파일 저장

정리된 코드는 [air_quality_etl.py](./air_quality_etl.py)에 있습니다.

### Case B. 에너지 사용 데이터

2015~2024년 기간의 월별 에너지 사용 데이터를 같은 방식으로 수집하고 통합했습니다.

수행 내용:
- 연도·월별 API 반복 호출
- JSON 파일 저장
- 필요한 항목만 선택
- 전기·가스·수도·난방 데이터를 숫자형으로 변환
- 월별 데이터를 하나의 표로 통합
- CSV 저장

정리된 코드는 [energy_use_etl.py](./energy_use_etl.py)에 있습니다.

## 사용 기술

`Python` · `requests` · `JSON` · `pandas` · `data cleaning` · `ETL` · `CSV`

## 제조업과의 연결 방향

현재 코드는 공공 데이터를 대상으로 한 학업 과제입니다. 제조 데이터를 직접 사용한 것은 아닙니다.

다만 제조현장에서도 분석 전에 다음 작업이 필요합니다.

- LOT / Batch별 공정조건을 한곳에 모으기
- 설비 로그와 품질검사 결과 연결하기
- 문자·숫자·날짜 형식을 일관되게 정리하기
- 결측치와 잘못된 값을 확인하기
- 분석용 데이터셋으로 통합하기

따라서 이 프로젝트는 **분석 이전 단계에서 필요한 데이터 수집·정리·통합 역량**을 보여주는 기초 사례로 두고, 이후 합성 제조 데이터로 확장할 예정입니다.
